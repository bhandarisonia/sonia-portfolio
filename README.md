# Sonia Sphere - Soniya Bhandari Portfolio

Modern, high-performance, and attractive personal portfolio website for **Soniya Bhandari** under the brand identity **Sonia Sphere** (Website Developer & Digital Marketing Specialist).

## 🌟 Key Features

- **"Sonia Sphere" 3D Shining Logo**: Features a luminous 3D sphere emblem with a golden-cyan rotating orbital halo, specular glass reflection, ambient pulse, and dynamic rainbow-shine animated typography.
- **Dark & Light Mode Toggle**: One-click theme switcher with persistent local storage.
- **Dynamic Typing Animation**: Smooth interactive title transitions in the hero section.
- **Profile Showcase**: Includes `soniaphoto.jpeg` with glowing glassmorphism borders and floating achievement chips.
- **Filterable Showcase**:
  - **Projects Filter**: Switch between *All*, *Web Development*, and *SEO & Marketing*.
  - **Skills Filter**: Filter across *Frontend*, *Backend & Database*, *CMS & Tools*, *Digital Marketing*, and *Other Skills*.
- **Interactive Contact Form**: Client-side validation, sending simulation, sweet notification toast, and pre-filled email client fallback.
- **Fully Responsive**: Optimized for phones, tablets, laptops, and ultra-wide desktops.
- **No Heavy Build Tooling Required**: Pure HTML5, CSS3, and modern Vanilla JavaScript with Google Fonts and FontAwesome 6 icons.

## 🚀 How to Run Locally

Double-click `index.html` to open it in your browser (Chrome, Edge, Firefox, Safari).

Alternatively, launch a local server:
```bash
# Using Python
python -m http.server 3000

# Using Node.js npx
npx serve .
```
Then visit `http://localhost:3000`.

## 📁 File Structure

- `index.html` - Semantic HTML5 portfolio markup with all content & meta tags.
- `style.css` - Custom design system, CSS variables, glassmorphic styling, animations, and responsive layouts.
- `script.js` - Dynamic typing, mobile menu, project/skill filters, theme switcher, and contact form logic.
- `soniaphoto.jpeg` - Official profile photograph.
